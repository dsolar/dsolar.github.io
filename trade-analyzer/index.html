Checking for the ESPN browser extension…

Install the test extension
  1. Download ESPN Connect and extract the ZIP.
  2. Open chrome://extensions or edge://extensions.
  3. Turn on Developer mode, choose Load unpacked, and select the extracted folder containing manifest.json.
  4. Refresh this page, then choose Connect ESPN.

This first version is installed directly. You don’t need to copy passwords or session cookies.
